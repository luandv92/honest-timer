honest-timer — live demo

This page is a single, self-contained HTML file: open it directly from disk (double-click, no server) and the countdown below still works. Reload the page a few times — the deadline does not move.

Launch-week pricing for Product X ends in:

$47 — price rises automatically when the timer hits zero

$47 $67 — launch-week pricing has ended

(Set to 2 minutes here so you can see it expire quickly. In production you'd use data-honest-timer-minutes="2880" for a 48h window, for example.)

How this page is wired

<span data-honest-timer
      data-honest-timer-key="demo-sale"
      data-honest-timer-minutes="2"></span>

<span data-honest-timer-before="demo-sale">$47</span>
<span data-honest-timer-after="demo-sale" style="display:none">$67</span>

<span data-honest-timer-key="demo-sale"
      data-honest-timer-raise-to="$67">$47</span>
